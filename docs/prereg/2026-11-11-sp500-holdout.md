# Pre-registration: S&P 500 holdout test (written 2026-11-11, before any data was pulled)

**Why:** post-earnings drift (PEAD) was strong over 1999-2023 on 56 megacaps (t 3.86), but the
3-year holdout had only ~124 events per quintile, too few to confirm (t 0.42). Retest the
surviving and near-miss signals on ~9x more stocks.

**Universe:** S&P 500 members on 2023-11-01, rebuilt from Wikipedia's current list + dated
changes (undo every change dated after 2023-11-01). This list was knowable on that date, so
there is no hindsight in stock selection. Stocks Yahoo can't price are dropped and counted.

**Test window:** 2023-11-01 to the latest bar. Rules are copied unchanged from the original labs.

| Code | Signal (unchanged) | Measure |
|---|---|---|
| T4b | 3+ down closes -> buy next open, sell 3 opens later | excess over a random 3-day window in the same stock, same window |
| T7  | close < 9-day mean - 2 sd -> buy next open, sell the open after it closes back above the mean (max 9 days) | same, matched hold |
| T6  | 3-, 6- and 9-day cycle bands all turn up -> buy next open, hold 3 | same |
| PEAD| reaction-day close -> 60 trading days later, minus SPY, net 5 bp; quintiles of EPS surprise within each calendar year | top-quintile minus bottom-quintile spread |

Costs: 5 bp round trip per stock trade.

**Pass bar (4 tests, Bonferroni):** p < 0.0125 one-sided, positive in both 2024 and 2025, and
for T4b/T7/T6 the calendar-shift luck test (1,000 shifts) must also clear p < 0.0125.
t-stats for the trade signals are computed on the daily average of trades (so 400 stocks
moving together on one day count once, not 400 times).

No parameter is tuned. If something fails, it fails.
